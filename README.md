# Kayo — Crypto Password Manager `In Progress`

Графический менеджер паролей на Python с Zero-Knowledge шифрованием. Данные хранятся локально в изолированном JSON-файле и защищены современными криптографическими алгоритмами.

---

## Ключевые возможности

* **Zero-Knowledge Архитектура**: Мастер-пароль не хранится в открытом виде. Шифрование происходит на лету.
* **Полноценный GUI**: Интерфейс написан на Tkinter. Никаких консольных `input()`.
* **Умное окно записи**: Функция `write_pass` автоматически определяет, создать новый аккаунт или обновить существующий.
* **Интерактивный список**: Удобный просмотр и выбор сервисов через динамический `Listbox`.
* **Безопасность интерфейса**: Использование модальных окон (`grab_set()`) предотвращает дублирование окон и баги логики.

---

## Безопасность и Технологии

* **Python 3.x** — основная среда разработки.
* **Tkinter** — графический интерфейс.
* **Cryptography (Fernet)** — симметричное шифрование базы данных по алгоритму AES.
* **PBKDF2HMAC + Соль** — безопасная генерация ключа из мастер-пароля для защиты от брутфорса.
* **JSON** — структурированное хранение связок сервис/логин/пароль.

## История обновлений (Changelog)

### v6.0 (Текущая версия)
* Полный переход на GUI (Tkinter), полный отказ от консоли.
* Создана универсальная функция записи/обновления данных `write_pass`.
* Реализован интерактивный вывод сервисов через `Listbox` с обработкой кликов.
* Связана логика авторизации и криптографии: чтение мастер-пароля из поля ввода -> генерация ключа -> дешифровка JSON.
* Внедрена защита фокуса окон через `.grab_set()`.

### v5.0
* Интегрировано AES-шифрование через библиотеку `Fernet`.
* Добавлена авторизация по мастер-паролю.
* Внедрена защита ключа с помощью PBKDF2HMAC и соли.

### v4.0
* Миграция с формата TXT на структурированный JSON.
* Добавлено поле `login` для хранения учетных записей.
* Реализована функция Smart Update (пропуск изменения логина по Enter).

### v3.1 – v3.0
* Добавлен встроенный генератор безопасных случайных паролей.
* Рефакторинг кода: разбиение на логические функции.
* Добавлены проверки на пустой ввод и валидация выбора.

### v1.0 – v2.0
* Переход на постоянное хранение данных в файле `data.txt`.
* Реализовано первое консольное интерактивное меню с нумерацией.
* Базовая логика на структурах `dict` (работа внутри одной сессии).
