# Kayo — Crypto Password Manager (In Progress) 🚀

Графический менеджер паролей на Python (Tkinter) с Zero-Knowledge шифрованием.

## Текущий статус проекта (v6.0-alpha) (Текущая)
Проект находится в процессе миграции с консольного интерфейса на полноценный GUI. 

### Version 5.0 
- **Шифрование**: Данные теперь защищены алгоритмом AES (через библиотеку Fernet).
- **Мастер-пароль**: Доступ к базе возможен только при вводе правильного ключа.
- **Безопасное хранение ключа**: Используется соль (PBKDF2HMAC) для защиты от взлома.

### Version 4.0
- **Новый формат**: Переход с TXT на JSON для надежного хранения структурированных данных.
- **Поля данных**: Теперь сохраняются не только пароли, но и логины.
- **Smart Update**: При обновлении можно нажать Enter, чтобы оставить старый логин.

### Version 3.1
- **Генерация**: Теперь код при запросе генерации создает безопасный пароль.

### Version 3.0
- **Рефакторинг**: Весь код разбит на логические блоки (функции), что делает его чистым и удобным для расширения.
- **Улучшенная навигация**: Добавлены проверки на пустой ввод и корректный выбор сервиса.
- **Глобальное состояние**: Использование единого списка данных для всех функций.

### Version 2.0
- **Файловое хранилище**: Теперь пароли сохраняются в `data.txt` и не стираются после закрытия программы.
- **Интерактивное меню**: Можно выбирать между добавлением нового пароля и просмотром старых.
- **Умный список**: Программа сама нумерует сервисы для удобного выбора.

### Version 1.0
- Основа логики на словарях (`dict`).
- Работа только внутри одной сессии (без сохранения).
